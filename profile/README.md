# Tanġware

Truly personal devices, mixed in everyday life.

**The only end-to-end AI studio for hardware development.**

Consumer electronics, from idea to shipped: design, electronics, firmware, marketing and manufacturing, all as code.

*The source code of reality.*

### Start here

- [**library**](https://github.com/Tangware/library): the open CAD library behind Tanġware Studio, with its Claude Code plugin. Model consumer electronics as code with build123d.

Needs git and [uv](https://docs.astral.sh/uv/).

```sh
uvx --from tangware==0.1.0 cad new my-product --name "My product"
claude plugin marketplace add Tangware/library
claude plugin install tangware@tangware
```

Build it in [Tanġware Studio](https://tangware.com/studio).
